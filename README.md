# session-details

A Claude Code mod: a live side pane mirroring the desktop app's session details (environment, context, outputs, background tasks). `/session-details` reopens it.

## Install

At the prompt of a terminal session:

```
/plugin install session-details --marketplace ahmad-yahea/session-details
```

From a shell:

```
claude plugin install session-details --marketplace ahmad-yahea/session-details
```
